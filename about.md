# Pacyrinth Game

A 3D labyrinth game built with the Godot Engine.

## Features

- **3D Gameplay**: Navigate a 3D labyrinth.
- **Controls**: Tilt mechanics to control movement.
- **In-App Purchases**: Optional consumables and ad removal.

## Prerequisites

- Godot Engine 4.7.2 or later.

## Getting Started

1. Open the project in the Godot Editor by selecting the `game/` folder.
2. Ensure you have the necessary export templates installed.

## Building and Exporting

- To export for Android, ensure you have the Android build templates installed and configured.
